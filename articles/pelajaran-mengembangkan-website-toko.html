PENGEMBANGAN WEB

Pelajaran yang Saya Dapatkan Saat Mengembangkan Website Toko

Selama mengembangkan TOKOTOKI, saya belajar banyak hal yang tidak saya dapatkan kalau cuma baca teori. Berikut pelajaran yang paling berkesan buat saya — ditulis sebagai catatan belajar, bukan sebagai nasihat ahli.

Struktur project itu penting

Di awal saya asal menaruh file dan akhirnya bingung sendiri. Setelah project dirapikan — controller, model, dan halaman frontend masing-masing punya tempat — mencari dan memperbaiki kode jadi jauh lebih cepat.

Database, CRUD, dan validasi

Membuat CRUD produk mengajarkan saya cara merancang tabel dan relasi sederhana. Pelajaran pentingnya: validasi form tidak boleh cuma di browser. Data yang dikirim ke server harus divalidasi ulang di backend, karena input dari pengguna tidak pernah bisa dipercaya begitu saja.

Autentikasi dan role pengguna

Di TOKOTOKI ada tiga peran: admin, kasir, dan customer. Saya belajar bahwa pembatasan akses harus dicek di sisi server, bukan cuma disembunyikan di tampilan. Tombol yang disembunyikan tapi endpoint-nya terbuka tetap bisa diakses orang yang tahu caranya.

Responsive dan debugging

Saya belajar menguji tampilan di ukuran layar HP, bukan cuma di laptop. Untuk debugging, kebiasaan yang paling membantu saya adalah membaca pesan error sampai habis dan menguji satu perubahan dalam satu waktu, supaya jelas bagian mana yang bermasalah.

Testing memberi rasa aman

Menjalankan automated test setiap selesai mengubah kode membuat saya berani melakukan perubahan. Kalau ada yang rusak, test langsung memberi tahu. Saya masih belajar menulis test yang bagus, tapi manfaatnya langsung terasa.

Kesimpulannya: project kecil yang selesai dan berjalan mengajarkan lebih banyak daripada banyak tutorial yang tidak pernah dipraktikkan.
