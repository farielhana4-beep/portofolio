PEMBELAJARAN

Perjalanan Saya Mempelajari Web Development

Saya siswa SMK Negeri 1 Jenangan jurusan Rekayasa Perangkat Lunak. Tulisan ini merangkum perjalanan saya belajar web development sejauh ini — apa yang sudah saya pelajari dan apa yang masih ingin saya kembangkan.

Mulai dari dasar

Saya mulai dari HTML untuk struktur halaman, CSS untuk tampilan, dan JavaScript untuk interaksi. Tiga hal ini jadi fondasi segalanya. Sampai sekarang pun, setiap kali ada tampilan yang aneh, yang saya cek pertama kali tetap HTML dan CSS-nya.

Masuk ke backend dan database

Setelah cukup nyaman dengan frontend, saya belajar backend dasar: bagaimana server menerima request, mengolah data, dan mengembalikan tampilan. Saya juga belajar database dasar dan operasi CRUD. Di tahap ini saya sadar kalau aplikasi web itu pada dasarnya soal aliran data yang rapi.

Mencoba React dan Laravel

Saya lalu mencoba React untuk membangun antarmuka yang lebih interaktif, dan Laravel untuk backend yang lebih terstruktur. Keduanya dipakai di project TOKOTOKI, dan dari situlah saya benar-benar paham cara kerja keduanya — bukan dari tutorial, tapi dari error yang saya perbaiki sendiri.

Project membantu memahami materi

Materi pelajaran jadi jauh lebih nempel setelah saya pakai di project nyata. Konsep validasi, autentikasi, dan relasi database yang dulu cuma hafalan, sekarang jadi hal yang saya pakai setiap hari saat ngoding.

Yang masih ingin saya kembangkan

Saya masih ingin memperdalam JavaScript, memahami backend lebih jauh, dan belajar menulis test yang lebih baik. Target saya jelas: menjadi Junior Web Developer yang siap kerja — dan caranya adalah terus membuat project sambil belajar.
