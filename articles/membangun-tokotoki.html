Membangun TOKOTOKI: Dari Ide hingga Website Toko Kerajinan

TOKOTOKI berawal dari ide sederhana: membuat website toko untuk produk kerajinan tangan dan dekorasi. Saya ingin punya satu project utuh yang benar-benar bisa dipakai — ada katalognya, ada keranjangnya, ada halaman checkout-nya, dan ada dashboard untuk admin.

Konsep websitenya

Konsepnya adalah toko online kecil yang rapi dan mudah dipakai. Pengunjung bisa melihat-lihat produk tanpa harus daftar dulu. Produk dikelompokkan ke dalam kategori — Dekorasi, Aksesoris, Perlengkapan Rumah, dan Souvenir — supaya pembeli gampang menemukan yang mereka cari.

Fitur yang saya buat

  • Katalog produk dengan kategori dan pencarian
  • Halaman detail untuk setiap produk
  • Keranjang belanja dan checkout
  • Riwayat transaksi untuk pembeli
  • Dashboard admin untuk mengelola produk (CRUD), stok, dan transaksi
  • Role dan authorization untuk membedakan admin, kasir, dan customer
  • Tampilan responsive supaya nyaman dibuka di HP maupun laptop

Teknologi yang dipakai

Project ini dibangun dengan Laravel di sisi backend, Inertia.js sebagai penghubung, React.js untuk antarmuka, Tailwind CSS untuk styling, dan MySQL untuk databasenya. Memakai kombinasi ini sekaligus membuat saya belajar bagaimana frontend dan backend bekerja sama dalam satu aplikasi.

Yang saya pelajari

Hal terbesar yang saya pelajari adalah bahwa membuat website toko bukan cuma soal tampilan. Alur datanya harus benar: stok berkurang saat checkout, transaksi tercatat rapi, dan setiap peran pengguna dibatasi sesuai haknya. Saya juga belajar bahwa desain yang sederhana tapi konsisten jauh lebih enak dipakai daripada desain yang ramai tapi membingungkan.

TOKOTOKI masih terus saya kembangkan, tapi project ini jadi bukti buat saya sendiri bahwa saya bisa membangun aplikasi web dari awal sampai bisa dipakai.
