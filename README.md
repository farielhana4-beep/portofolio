# Portfolio Fariel Hana Putra

Website portfolio statis untuk presentasi Uji Serkom Junior Web Developer.

## Teknologi

- HTML5
- CSS3
- JavaScript vanilla

Tidak menggunakan database, Composer, Node.js, atau build system.

## Menjalankan di Laragon

1. Pastikan Apache Laragon berjalan.
2. Buka `http://localhost/portfolio-fariel/`.
3. Jika Laragon telah membuat virtual host untuk folder baru, URL alternatifnya adalah `http://portfolio-fariel.test`.
4. Alternatif terakhir: buka `index.html` langsung melalui browser.

## Struktur

```text
portfolio-fariel/
├── index.html
├── assets/css/style.css
├── assets/js/main.js
├── assets/images/
├── assets/icons/favicon.svg
└── README.md
```

## Tautan TOKOTOKI

URL toko disimpan pada konstanta `storeUrl` di `assets/js/main.js`. Ubah nilainya ketika URL deployment yang sebenarnya sudah tersedia.

## Asset dan data

Masukkan foto profil pada `assets/images/profile`, gambar project pada `assets/images/projects`, sertifikat pada `assets/images/certificates`, dan dokumentasi kegiatan pada `assets/images/activities`.

Semua teks `[ISI SENDIRI]` harus diganti dengan data dan asset asli sebelum presentasi. Jangan menampilkan data placeholder sebagai pengalaman, sertifikat, prestasi, atau kontak nyata.
